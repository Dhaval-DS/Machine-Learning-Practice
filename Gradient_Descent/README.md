# A Deep Dive into Gradient Descent for Linear Regression

This project provides a comprehensive, hands-on exploration of the **Gradient Descent** algorithm, a fundamental optimization technique used to train machine learning models. The repository contains a collection of Jupyter Notebooks that break down the algorithm from its core mathematical principles to advanced 3D visualizations.

---
## The Learning Journey: From Theory to Visualization

This project is structured as a step-by-step guide to mastering Gradient Descent:

### 1. The Math Behind the Magic (`step_by_step_Gradient_Descent.ipynb`)
* **Concept**: This notebook demystifies the algorithm by performing the calculations for a single iteration of Gradient Descent **manually** on a small, sample dataset.
* **Key Takeaway**: Provides a clear understanding of how the slope (`m`) and intercept (`b`) are updated based on the loss function's partial derivatives.

### 2. Building a Regressor From Scratch (`gradient-descent-code-from-scratch.ipynb`)
* **Concept**: This notebook implements a complete Simple Linear Regression model using Gradient Descent from scratch by creating a custom Python class `GDRegressor`.
* **Features**: The class includes `fit()` and `predict()` methods, mimicking the structure of a scikit-learn model.

### 3. Visualizing the Descent (2D Animations)
These notebooks use animations to show how the algorithm iteratively finds the best-fit line.

* **`gradient-descent-animation(onlyb).ipynb`**: This notebook visualizes the process of optimizing **only the intercept (b)**, showing how the regression line moves up and down to find its optimal position.
* **`gradient-descent-animation(both-m-and-b).ipynb`**: This notebook provides a complete animation, showing how both the **slope (m) and intercept (b)** are updated simultaneously in each epoch to converge on the best-fit line.

### 4. The 3D Loss Landscape (`gradient-descent-3d.ipynb`)
* **Concept**: This advanced notebook visualizes the Gradient Descent algorithm's path in a **3D space**.
* **Visualization**: It plots the loss function as a 3D surface and animates the algorithm's "steps" as it moves from its starting point down the slope of the loss function towards the point of minimum error.

---
## Dataset

All demonstrations use a synthetic dataset generated by scikit-learn's `make_regression` function, which allows for controlled experiments and clear visualizations.
