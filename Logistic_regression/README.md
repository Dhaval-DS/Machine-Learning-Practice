# Logistic Regression and the Perceptron Algorithm from Scratch

This project provides a comprehensive guide to building linear classifiers, contrasting **Logistic Regression** (using Batch Gradient Descent) with the **Perceptron Algorithm** (using the stochastic "Perceptron trick").

The notebooks demonstrate how to implement these algorithms from scratch, visualize their decision boundaries, and compare their learning processes against each other and against standard `scikit-learn` implementations.

---
## Dataset 📊

All three notebooks use a synthetic, 2-dimensional, 2-class dataset generated by `sklearn.datasets.make_classification`. This provides a simple, linearly separable dataset ideal for visualizing the decision boundaries of different linear classifiers.

---
## Notebooks and Methodology ⚙️

### 1. `logistic Regression (Gradient Descent).ipynb`
* **Concept**: This notebook implements **Logistic Regression** using **Batch Gradient Descent** from scratch.
* **Methodology**:
    * A `gd` function is defined, which uses the **sigmoid** activation function to calculate `y_hat`.
    * It iteratively updates the model's weights by calculating the gradient of the loss function using the **entire training dataset** in each epoch (5000 iterations).
    * The final plot compares the decision boundary from the custom Gradient Descent model directly against the boundary generated by `sklearn.linear_model.LogisticRegression`, showing they converge to the same solution.

### 2. `perceptron-trick.ipynb`
* **Concept**: This notebook implements the classic **Perceptron Algorithm** using the "Perceptron trick," which is a form of **Stochastic Gradient Descent (SGD)**.
* **Methodology**:
    * It defines a `perceptron` function that uses a simple **step function** (`1 if z > 0 else 0`) as its activation function.
    * Instead of processing the whole dataset, it iterates 1000 times, picking **one random sample** at a time (`j`) and updating the weights based on the error of just that single point.
    * The notebook also creates an **animation** (`FuncAnimation`) to visualize the learning process, showing the decision boundary line adjusting its position and angle over 200 epochs as it learns from individual data points.

### 3. `perceptron trick (sigmoid function).ipynb`
* **Concept**: This notebook provides a direct comparison between three different linear classifier implementations.
* **Methodology**: It builds and plots the decision boundaries for:
    1.  **Perceptron (Step Function)**: A from-scratch implementation using the stochastic perceptron trick with a `step` function.
    2.  **Sklearn Logistic Regression**: The standard `LogisticRegression` model, which uses optimization solvers.
    3.  **Perceptron (Sigmoid Function)**: A from-scratch implementation using the perceptron trick (stochastic updates) but with a **sigmoid** activation function. This effectively demonstrates a stochastic version of Logistic Regression.
* **Outcome**: The final plot shows all three decision boundaries on the same graph, allowing for a clear visual comparison of how the activation function (step vs. sigmoid) and the optimization method (batch vs. stochastic) affect the final model.
