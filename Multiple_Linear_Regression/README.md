# Multiple Linear Regression: From Scratch and with scikit-learn

This project provides a comprehensive look at **Multiple Linear Regression**, demonstrating how to build a predictive model from two different perspectives:
1.  **From Scratch**: By creating a custom Python class that implements the algorithm using the Gradient Descent optimization technique.
2.  **Using scikit-learn**: By leveraging the powerful, pre-built `LinearRegression` model from the scikit-learn library to train a model on synthetic data.

---
## Implementations

### 1. Multiple Linear Regression From Scratch (`code_from_scratch.ipynb`)
* **Concept**: This notebook demystifies the mechanics of multiple linear regression by building a custom class named `MyLR` that uses Gradient Descent to find the optimal coefficients.
* **Dataset**: Uses the **Diabetes dataset** from scikit-learn's built-in datasets.
* **Methodology**:
    * A custom `MyLR` class is defined with `fit()` and `predict()` methods.
    * The `fit()` method uses an iterative **Gradient Descent** algorithm to learn the model's coefficients and intercept by minimizing the loss function.
    * The notebook compares the results of the custom model with scikit-learn's `LinearRegression` model to validate its correctness.

### 2. Multiple Linear Regression with scikit-learn (`Multiple_linear_regression.ipynb`)
* **Concept**: This notebook shows the standard, efficient way to implement multiple linear regression on a dataset with two features.
* **Dataset**: Uses a **synthetic dataset** generated by scikit-learn's `make_regression` function.
* **Methodology**:
    * The data is split into training and testing sets.
    * An instance of `LinearRegression` is trained on the data, and its performance is evaluated using metrics like R² score.
    * The notebook includes an interactive **3D scatter plot** created with **Plotly** to visualize the data points and the resulting regression plane.
